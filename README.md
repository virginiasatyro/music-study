# music-study

Aplicação web para apoiar os estudos de música.

## Como executar

Abra `index.html` no navegador. O projeto usa apenas HTML, CSS e JavaScript nativos.

## Estrutura

- `index.html`: página principal.
- `css/style.css`: estilos da aplicação.
- `js/app.js`: ponto de entrada da interface.
- `js/database.js`: persistência e acesso a dados.
- `js/books.js`: gerenciamento de livros de estudo.
- `js/content.js`: conteúdo dos estudos.
- `js/study-session.js`: sessões de estudo.
- `js/review-scheduler.js`: agendamento de revisões.
- `js/backup.js`: importação e exportação de dados.
